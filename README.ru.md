# TPAK Packer — архиватор `.pak` (TPAK v7)

Упаковщик и распаковщик архивов `.pak` (TPAK v7) с интерфейсом
с двухпанельным интерфейсом и отдельным обработчиком архива без GUI. Формат реализован
самостоятельно, без сторонних библиотек.

**English version:** [README.md](README.md)

![интерфейс](screenshot.png)

## Возможности

| Действие | Как |
|---|---|
| Открыть архив | **Файл → Открыть** / `Ctrl+O`; путь можно передать аргументом: `TPAK_Packer.exe game.pak` |
| Потоковое открытие | пак не загружается в память целиком: большие архивы открываются мгновенно, файлы читаются по мере надобности |
| Дерево папок | слева; один клик открывает папку, `..` — на уровень вверх |
| Список файлов | имя, размер, упаковано, сжатие, метод, число чанков; сортировка по клику на заголовок |
| Поиск | поле **Поиск** (`Ctrl+F`) по всем записям архива |
| Извлечь | **Извлечь в папку…** (`Ctrl+E`) — выбранные записи или всё; **Извлечь сюда** — рядом с архивом |
| Добавить | файлы или целую папку (в текущую папку архива) |
| Удалить | `Del` |
| Переименовать | `F2` |
| Просмотр | двойной клик: текст или hex-дамп (до 256 КиБ) |
| Тест | чтение архива чанк за чанком со сверкой размеров |
| Проверка пересборкой | собрать во временный файл и сравнить SHA-256 каждой записи |
| Создать | **Создать из папки…** — упаковать каталог в новый `.pak` |
| Сохранить | `Ctrl+S` (с копией `.bak`), **Сохранить как…** — в новый файл |
| Свойства | версия формата, число файлов, размеры, наличие изменений |

Изменения (добавление, удаление, переименование) копятся в памяти и
записываются только по **Сохранить**; до этого исходный архив не меняется.

## Обработчик архива

`pak_handler.py` — высокоуровневый API без GUI:

```python
from pak_handler import PakArchive

h = PakArchive().open("archive.pak")
for e in h.entries():
    print(e["name"], e["size"])

h.extract(["folder/file.txt"], "out")
h.add_file("new.txt")
h.save()          # рядом с исходником появится .bak
h.test()          # список проблем (пусто = архив читается целиком)
```

Методы: `open/new/close`, `entries`, `folders`, `read`, `extract`,
`add_bytes/add_file/add_dir`, `delete`, `rename`, `save`, `create_from_dir`,
`test`, `verify_repack`. Небезопасные имена (`..`, абсолютные пути) при
извлечении пропускаются.

## Запуск из исходников

```bash
python pak_gui.py                 # пустое окно
python pak_gui.py game/data.pak   # сразу открыть архив
```

Язык интерфейса определяется по языку ОС: русский для русской Windows, иначе английский (переопределяется `PAKER_LANG=ru|en`).

Нужен Python 3.9+ с tkinter (входит в стандартный установщик Windows).
Сторонних зависимостей для запуска нет.

## Сборка из исходников

### Что нужно

* Windows 10/11;
* **Python 3.9+** с python.org (стандартный установщик включает tkinter);
* для запуска приложения сторонних библиотек не нужно.

Проверка интерпретатора:

```bash
python --version
python -c "import tkinter; print(tkinter.TkVersion)"
```

### Запуск без сборки

```bash
git clone <repo-url> paker
cd paker
python pak_gui.py                 # пустое окно
python pak_gui.py path/to/game.pak
```

### Сборка exe

Один раз ставим PyInstaller:

```bash
python -m pip install --upgrade pyinstaller
```

Дальше — скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

или вручную:

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name TPAK_Packer --icon icons\tpak.ico `
  --add-data "icons;icons" pak_gui.py
```

Результат — **`dist\TPAK_Packer.exe`**: один файл без консоли, с иконкой и
встроенной папкой `icons/` (если её нет, приложение показывает текстовые
кнопки).

`build.ps1` делает то же самое: обновляет PyInstaller, передаёт `icons/`
внутрь exe и печатает путь к результату.

### Тесты перед сборкой

```bash
python -m unittest discover -s tests -v
```

Семь тестов покрывают обработчик архива (создание, список, чтение,
извлечение, добавление, удаление, переименование, сохранение, тест
целостности, проверку пересборкой, защиту от `..`) и smoke-тест GUI
(открытие архива и список записей).

### Чистая пересборка

```bash
rmdir /s /q build dist
```

`TPAK_Packer.spec` PyInstaller создаёт заново при каждой сборке — в
репозитории он не обязателен. Если антивирус удаляет свежий one-file exe,
добавь `dist\` в исключения или собирай с `--onedir` вместо `--onefile`.

## Формат

TPAK v7: заголовок, таблица файлов, таблица чанков, упакованные данные
(deflate/store), имена в зашифрованной таблице. Чанки TFD (текстуры)
разбиваются по уровням мипов так же, как это делает игра. Записанные архивы
совместимы с игрой: игра читает loose-файлы из `data/` поверх паков.
